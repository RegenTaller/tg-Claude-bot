# Telegram-бот для Claude

Приватный бот: пересылает ваши сообщения в Claude API и присылает ответы обратно. Кнопками выбираются модель (Opus 5.5, Sonnet 5.5, Haiku 5.5, Fable 5.1) и effort (low … max).

## Документация

- **[docs/deploy.md](docs/deploy.md)** — пошаговый запуск на своём VDS: API-ключ и оплата, бот в Telegram, Docker рядом с VPN, обновление, логи, что делать при проблемах.
- **[docs/architecture.md](docs/architecture.md)** — как всё устроено: понятия Telegram Bot API и Claude API, путь сообщения через код, назначение каждого файла и функции, из чего складывается стоимость.
- **[docs/review.md](docs/review.md)** — результаты проверки кода (октябрь 2026): что было найдено и как исправлено.

## Что умеет

- Текст, фото (в том числе альбомы), PDF и текстовые файлы: код, логи, CSV и т.п. Длинный текст, который Telegram разрезал на части, склеивается обратно.
- Ответ появляется постепенно, по мере генерации, затем форматируется: жирный шрифт, код, списки.
- Диалог с памятью: бот помнит контекст, пока не нажать «🆕 Новый диалог» (`/new`).
- У каждого пользователя свои модель, effort и история.
- Доступ только по списку Telegram ID. Остальным бот отвечает «нет доступа» и показывает их ID.
- `/usage` — примерный расход в долларах за 30 дней (админ видит всех). Можно задать месячный лимит на пользователя.
- Админ выдаёт и отзывает доступ без перезапуска: `/allow 123456789`, `/deny 123456789`.
- Защитные проверки: размер запроса и файлов, ужатие картинок, понятные сообщения об ошибках API, предупреждение о дорогом длинном диалоге.

## Архитектура в двух словах

```
Telegram  ⇄  бот (Python, aiogram, long polling)  ⇄  Claude API (ваш API-ключ)
                    │
                    └── SQLite: настройки, история диалогов, расход
```

Бот сам опрашивает Telegram (long polling), поэтому публичный IP, домен и HTTPS не нужны. Но работать он должен постоянно, поэтому его место — на сервере, а не на домашнем компьютере.

## Быстрый старт (если Docker уже знаком)

```bash
git clone https://github.com/RegenTaller/tg-Claude-bot.git && cd tg-Claude-bot
cp .env.example .env && nano .env && chmod 600 .env   # токен бота, ключ API, свой Telegram ID
mkdir -p data && sudo chown 10001:10001 data          # контейнер работает не от root
sudo docker compose up -d --build
sudo docker compose logs -f
```

Подробности и подводные камни — в [docs/deploy.md](docs/deploy.md). Прежде чем платить, прочитайте там шаг 1 о поддерживаемых странах.

## Стоимость

Вы платите только за токены API по тарифам Anthropic. На октябрь 2026, за 1M токенов вход / выход: Opus 5.5 — $4/$20, Sonnet 5.5 — $2/$10, Haiku 5.5 — $0.10/$0.50 (для промптов больше 100K — $0.50/$2.50), Fable 5.1 — $10/$50. Каждый ход отправляет всю историю диалога, поэтому длинные диалоги дорожают; кэширование это смягчает. Когда тема сменилась, начинайте новый диалог. Подробнее и о том, насколько корректно сравнивать модели по цене за токен, — в [docs/architecture.md](docs/architecture.md#6-деньги).

## Разработка

```bash
python -m venv .venv && . .venv/bin/activate
pip install -r requirements-dev.txt
python -m pytest     # тесты: настоящие aiogram и anthropic SDK, без сети
ruff check .
```

Без Docker бот запускается так: `set -a && . ./.env && set +a && DB_PATH=./data/bot.sqlite3 python -m bot.main` (нужен Python 3.10+).
