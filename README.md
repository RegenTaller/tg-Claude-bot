# Telegram-бот для Claude

Приватный бот: пересылает ваши сообщения в Claude API и присылает ответы обратно. Кнопками выбираются модель (Opus 5.5, Sonnet 5.5, Haiku 5.5, Fable 5.1) и effort (low … max).

## Что умеет

- Текст, фото, PDF и текстовые файлы (код, логи, CSV и т.п.).
- Ответ появляется постепенно, по мере генерации, затем форматируется (жирный, код, списки).
- Диалог с памятью: бот помнит контекст, пока не нажать «🆕 Новый диалог» (/new).
- У каждого пользователя свои модель, effort и история.
- Доступ только по списку Telegram ID. Остальным бот отвечает «нет доступа» и показывает их ID.
- /usage показывает примерный расход в долларах за 30 дней (админ видит всех).
- Админ выдаёт и отзывает доступ без перезапуска: `/allow 123456789`, `/deny 123456789`.

## Архитектура

```
Telegram  ⇄  бот (Python, aiogram, long polling)  ⇄  Claude API (ваш API-ключ)
                    │
                    └── SQLite: настройки, история диалогов, расход
```

- **Long polling**: бот сам опрашивает Telegram, поэтому публичный IP, домен и HTTPS не нужны. Достаточно любой машины, которая постоянно включена и имеет интернет.
- **Claude API** вызывается официальным SDK `anthropic` со стримингом. Effort передаётся в `output_config.effort`, размышления модели адаптивные (модель сама решает, сколько думать).
- **История** хранится только добавлением и целиком отправляется в API на каждом ходе; включено кэширование промпта, поэтому повторно отправленная история стоит в разы дешевле.
- **Отказы**: для Opus/Sonnet/Fable включён серверный fallback: если фильтр безопасности отклонит запрос, API сам повторит его на резервной модели. Бот пометит такой ответ.

## Установка

1. **Бот в Telegram.** Напишите [@BotFather](https://t.me/BotFather) → `/newbot`, получите токен.
2. **API-ключ.** Зарегистрируйтесь на [platform.claude.com](https://platform.claude.com), пополните баланс (Billing), создайте ключ (API keys). Рекомендую поставить месячный лимит расходов в настройках Limits.
3. **Настройки.**
   ```bash
   cp .env.example .env
   # впишите TELEGRAM_BOT_TOKEN, ANTHROPIC_API_KEY и свой Telegram ID в ALLOWED_USER_IDS
   ```
   Свой ID можно узнать, запустив бота и отправив ему `/id`.
4. **Запуск через Docker:**
   ```bash
   docker compose up -d --build
   docker compose logs -f
   ```
   **Или без Docker** (Python 3.11+):
   ```bash
   python -m venv venv && . venv/bin/activate
   pip install -r requirements.txt
   set -a && . ./.env && set +a
   DB_PATH=./data/bot.sqlite3 python -m bot.main
   ```
5. Отправьте боту `/start`. Чтобы добавить второго человека: пусть он отправит боту `/id`, а вы — `/allow <его ID>`.

## Стоимость

Платите только за токены API по тарифам Anthropic (на октябрь 2026, за 1M токенов вход/выход): Opus 5.5 — $4/$20, Sonnet 5.5 — $2/$10, Haiku 5.5 — $0.10/$0.50, Fable 5.1 — $10/$50. Каждый ход отправляет всю историю диалога, поэтому длинные диалоги дорожают: начинайте новый (/new), когда тема сменилась. Высокий effort означает больше токенов размышлений, а значит и дороже.

## Файлы

- `bot/main.py` — обработчики Telegram, кнопки, отправка ответов.
- `bot/claude.py` — запрос к Claude API, стриминг, fallback.
- `bot/storage.py` — SQLite.
- `bot/config.py` — список моделей, цены, переменные окружения.
